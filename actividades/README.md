
# Actividades

Esta carpeta contiene el banco de actividades reutilizables del curso.

Cada actividad tendrá una carpeta propia con un identificador estable y descriptivo:

```text
actividades/
├── diagnostico-inicial/
├── taller-transitividad/
└── seminario-categorias/
```

Dentro de cada actividad se almacenará únicamente su contenido reutilizable:

```text
taller-transitividad/
├── contenido.tex
└── recursos/
```

Los datos que cambian por periodo o grupo —fecha, grupo, plazo y enlace de entrega— no se almacenan aquí. Se definirán dentro de la edición correspondiente cuando la actividad sea utilizada.

Las modificaciones se registran mediante commits de Git. No se crearán copias con nombres como `final`, `final-2`, `corregida` o `ultima-version`.

Las entregas estudiantiles no se almacenan en el repositorio.
