
# Bibliografía

La base bibliográfica del curso se almacena en:

```text
referencias.bib
```

Las referencias se organizan en dos capas:

bibliografía base: entradas con keywords = {base};
bibliografía complementaria: entradas sin la palabra clave base.

El programa imprime primero la bibliografía base y después las referencias complementarias.
La entrada provisional incluida en la plantilla debe reemplazarse al incorporar la bibliografía real del curso.
